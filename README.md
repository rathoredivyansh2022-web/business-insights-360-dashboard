# 📊 Business Insights 360 – Power BI Project

## 🚀 Project Overview
Business Insights 360 is an end-to-end analytics solution built using Power BI on over 1 million rows of raw business data. The goal of this project is to transform complex data into actionable insights and support strategic decision-making.

## 🎯 Problem Statement
Organizations often face challenges in analyzing large volumes of business data efficiently. This project solves that problem by creating an interactive and centralized dashboard that tracks key financial and operational metrics.

## 📊 Business Concepts Covered
- Gross Price  
- Pre-invoice & Post-invoice Deductions  
- Net Invoice Sales  
- Gross Margin  
- Net Sales  
- Net Profit  
- COGS (Cost of Goods Sold)  
- YTD (Year-to-Date)  
- YTG (Year-to-Go)  

## 💡 Key Insights
- Identified revenue-driving products and regions  
- Tracked profit margins across different segments  
- Highlighted cost-heavy areas impacting profitability  
- Analyzed sales trends using YTD and YTG metrics  
- Improved visibility into financial performance
